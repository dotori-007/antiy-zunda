================================================================================
           즌다몬(ずんだもん) 데스크톱 Live2D 컴패니언 가이드
================================================================================

1. 개요 (Overview)
--------------------------------------------------------------------------------
본 프로그램은 Windows 투명 윈도우 위에 즌다몬 Live2D 모델을 표시하고,
VOICEVOX 음성 합성 엔진과 실시간 립싱크(입 모양 동기화)를 제공하는
데스크톱 마스코트 및 AI 에이전트 연동 컴패니언입니다.


2. 화면 조작 방법
--------------------------------------------------------------------------------
* 마스코트 이동 (Drag & Move):
  - 마스코트 영역을 [마우스 좌클릭 드래그]하면 화면 내 원하는 위치로 이동합니다.

* 시선 및 마우스 추적 (Full-screen Eye Tracking):
  - 모니터 전체 영역의 마우스 커서 위치를 실시간으로 추적하여
    커서가 위치한 방향으로 시선과 고개를 자연스럽게 회전합니다.


3. 단축키 가이드 (Shortcuts)
--------------------------------------------------------------------------------
마스코트 창을 클릭하여 활성화한 상태에서 아래 단축키를 사용할 수 있습니다:

[ 표정 변경 ]
  • Ctrl + 1 : 미소 (exp_smile)
  • Ctrl + 2 : 활짝 (exp_laugh)
  • Ctrl + 3 : 부끄 (exp_shy)
  • Ctrl + 4 : 깜짝 (exp_surprise)
  • Ctrl + 5 : 삐짐 (exp_angry)
  • Ctrl + 6 : 시무룩 (exp_sad)
  • Ctrl + 7 : 졸림 (exp_sleep)
  • Ctrl + 8 : 초롱 (exp_01)
  • Ctrl + 9 : 신남 (exp_laugh2)
  • Ctrl + 0 : 기본 표정 초기화

[ 크기 및 배율 조절 ]
  • Ctrl + [ : 캔버스 창 크기 50px 축소
  • Ctrl + ] : 캔버스 창 크기 50px 확대
  • Ctrl + - : 캐릭터 모델 배율 0.2 축소
  • Ctrl + + (또는 =) : 캐릭터 모델 배율 0.2 확대

[ 자막 설정 ]
  • Ctrl + U : 자막 표시 ON / OFF 토글
  • 자막 크기는 환경설정 패널에서 슬라이더 또는 프리셋 버튼으로 조절할 수 있습니다.

[ 독립 환경설정 창 ]
  • Ctrl + P  또는  Ctrl + , :
    화면과 별개로 독립된 환경설정 창을 띄웁니다.
    (표정 변경, 캔버스 크기 프리셋 및 입력, 모델 배율, 자막 ON/OFF 및 크기, 음성 테스트)


4. 실행 및 종료 방법
--------------------------------------------------------------------------------
* 무음 백그라운드 실행:
  - start_zundamon.vbs 실행 (콘솔 창 없이 투명 윈도우 기동)

* 콘솔 실행:
  - start_zundamon.bat 실행

* Windows 작업 스케줄러 실행:
  - PowerShell / 명령 프롬프트: schtasks /run /tn "ZundamonMascot"

* 프로그램 종료:
  - 작업 관리자(Ctrl+Shift+Esc)에서 'pythonw.exe' 프로세스 종료
  - 또는 PowerShell에서: Stop-Process -Name pythonw -Force


5. 음성 발화 CLI (speak.py)
--------------------------------------------------------------------------------
한국어 텍스트를 전달하면 일본어 음소 변환을 거쳐 즌다몬 음성으로 발화하며 립싱크합니다:

  실행 예시:
  python speak.py "안녕하세요! 즌다몬인 것이다!"


6. 주요 파일 구성
--------------------------------------------------------------------------------
* app.py              : Bottle 백엔드 서버 및 PyWebView 투명 윈도우 관리 (포트 8989)
* index.html          : PixiJS 및 Live2D Cubism 4 렌더링, 시선 추적, 립싱크, 자막 UI
* settings.html       : 실시간 연동 독립 환경설정 창 UI
* hangul_to_kana.py   : 한국어 텍스트 -> 일본어 가타카나 발음 변환 규칙 엔진
* speak.py            : 외부 프로세스/에이전트용 음성 발화 CLI 스크립트
* setup.bat           : 원클릭 환경 설치 배치 파일
* setup.ps1           : 파이썬 패키지 설치 및 스케줄러/스킬 등록 파워셸 스크립트
* start_zundamon.vbs  : 무음 GUI 실행 스크립트
* start_zundamon.bat  : 콘솔 실행 배치 파일
* config.json         : 사용자 정의 캔버스 너비/높이 설정 파일
