================================================================================
           즌다몬(ずんだもん) 데스크톱 Live2D 컴패니언 가이드
================================================================================

1. 개요 (Overview)
--------------------------------------------------------------------------------
본 프로그램은 투명한 윈도우 위에 즌다몬 Live2D 모델을 띄우고, VOICEVOX 음성 합성
엔진과 실시간 립싱크(입 모양 동기화)를 제공하는 데스크톱 마스코트입니다.
화면의 설정(⚙) 아이콘은 깔끔한 화면을 위해 숨김 처리되어 있으며, 마우스 및 단축키로
모든 기능을 편리하게 조작할 수 있습니다.


2. 화면 조작 방법
--------------------------------------------------------------------------------
* 화면 이동 (Drag & Move):
  - 마스코트 캐릭터 영역 어디든 [마우스 좌클릭 후 드래그]하면 화면 내 원하는 위치로 이동합니다.

* 창 크기 조절 (Corner Resize):
  - 마스코트 창 좌측 상단 모서리에 있는 리사이즈 핸들(⤡)을 [마우스 좌클릭 후 드래그]하면
    창 크기를 실시간으로 자유롭게 키우거나 줄일 수 있습니다.

* 시선 및 마우스 추적 (Full-screen Eye Tracking):
  - 마우스가 모니터 화면 어디에 있든 화면 전체를 100% 자유롭게 추적하여
    커서가 위치한 방향으로 시선과 고개를 자연스럽게 향합니다.


3. 단축키 가이드 (Shortcuts)
--------------------------------------------------------------------------------
마스코트 창을 클릭하여 활성화한 상태에서 아래 단축키를 사용할 수 있습니다:

[ 표정 변경 ]
  • Ctrl + 1 : 기본 (Default)
  • Ctrl + 2 : 화남 (Angry)
  • Ctrl + 3 : 슬픔 (Sad)
  • Ctrl + 4 : 졸림 (Sleepy)
  • Ctrl + 5 : 반짝반짝 (Sparkle)
  • Ctrl + 6 : 하트눈 (Heart)
  • Ctrl + 7 : 땀방울 (Sweat)
  • Ctrl + 8 : 울먹 (Tear)
  • Ctrl + 9 : 감정 표현 01 (Expression 01)

[ 크기 및 배율 조절 ]
  • Ctrl + [ : 캔버스 가로/세로 50px 축소
  • Ctrl + ] : 캔버스 가로/세로 50px 확대
  • Ctrl + - : 캐릭터 모델 배율 0.1 축소
  • Ctrl + + (또는 =) : 캐릭터 모델 배율 0.1 확대
  • Ctrl + 0 : 표정 및 배율 초기 상태로 리셋

[ 자막 설정 및 단축키 ]
  • Ctrl + U : 자막 표시 ON / OFF 토글
  • 자막 스타일: 배경 상자 및 테두리 없음, 연두색(#7CFC00) 텍스트 + 은은하고 자연스러운 소프트 그림자
  • 자막 크기 및 ON/OFF 세부 설정:
    설정창(Ctrl+P) 내 '자막 설정'에서 ON/OFF 토글 및
    글자 크기 프리셋(12px / 14px / 17px / 20px) 또는 슬라이더로 원하는 크기 조절 가능.
    (설정 변경 시 화면에 즉시 미리보기가 표시되고 영구 저장됩니다)

[ 설정창 호출 (환경설정 패널) ]
  • Ctrl + P  또는  Ctrl + , :
    설정 버튼이 화면에서 제거되어 있으나, 필요할 때 언제든 이 단축키를 누르면
    캔버스 크기 프리셋, 표정 변경, 자막 ON/OFF 및 크기 조절 모달 패널을 띄울 수 있습니다.


4. 실행 및 종료 방법
--------------------------------------------------------------------------------
* 완전 무음 백그라운드 실행 (추천):
  - start_zundamon.vbs 를 더블클릭하여 실행
  - 까만 CMD 창 깜빡임 없이 즉시 투명 윈도우로 기동됩니다.

* 배치 파일 실행:
  - start_zundamon.bat 실행

* Windows 작업 스케줄러 실행:
  - PowerShell / 명령 프롬프트: schtasks /run /tn "ZundamonMascot"

* 프로그램 종료:
  - 작업 관리자(Ctrl+Shift+Esc)에서 'pythonw.exe' 프로세스 종료
  - 또는 PowerShell에서: Stop-Process -Name pythonw -Force


5. 음성 출력 및 립싱크 (speak.py)
--------------------------------------------------------------------------------
한국어 문장을 전달하면 음소 변환을 거쳐 즌다몬 고유 음성으로 재생하며 립싱크합니다:

  명령어 예시:
  & "C:\2026591001\Python_3.10.11_64\python.exe" "C:\2026591001\source\zundamon_companion\speak.py" "안녕하세요! 즌다몬인 것이다!"


6. 주요 파일 구성
--------------------------------------------------------------------------------
* app.py              : 투명 Live2D 윈도우(PyWebView) 생성 및 로컬 백엔드 서버 (포트 8989)
* index.html          : PixiJS 및 Live2D Cubism 4 렌더링 캔버스 및 조작 인터페이스
* hangul_to_kana.py   : 한국어 문장을 자연스러운 일본어 가타카나 발음으로 자동 변환하는 규칙 엔진
* speak.py            : 외부 에이전트/사용자용 음성 발화 CLI 도구
* config.json         : 사용자가 조절한 캔버스 너비/높이 자동 저장 파일
* start_zundamon.vbs  : 콘솔 창 없는 무음 GUI 실행 스크립트
* start_zundamon.bat  : 기본 배치 실행 파일
* crash.log           : 앱 실행 로그 및 통신 기록
