================================================================================
           즌다몬(ずんだもん) 데스크톱 Live2D 컴패니언 가이드
================================================================================

1. 개요 (Overview)
--------------------------------------------------------------------------------
본 프로그램은 Windows 투명 윈도우 위에 즌다몬 Live2D 모델을 표시하고,
VOICEVOX 음성 합성 엔진과 실시간 립싱크(입 모양 동기화)를 제공하는
데스크톱 마스코트 및 AI 에이전트 연동 컴패니언입니다.
실시간 감정 대응 엔진(Emotion Mapping Engine)을 통해 대사의 의미와 맥락에 맞춰
Live2D 표정, 모션, 음성 스타일(아마아마, 노멀, 츤츤)이 전신 연동됩니다.


2. 화면 조작 방법
--------------------------------------------------------------------------------
* 마스코트 이동 (Drag & Move):
  - 마스코트 영역을 [마우스 좌클릭 드래그] 또는 [우클릭 드래그]하면 화면 내 원하는 위치로 이동합니다.

* 시선 및 마우스 추적 (Full-screen Eye Tracking):
  - 모니터 전체 영역의 마우스 커서 위치를 실시간으로 추적하여
    커서가 위치한 방향으로 시선과 고개를 자연스럽게 회전합니다.


3. 단축키 가이드 (Shortcuts)
--------------------------------------------------------------------------------
마스코트 창을 클릭하여 활성화한 상태에서 아래 단축키를 사용할 수 있습니다:

[ 표정 변경 ]
  • Ctrl + 1 : 미소 (exp_smile)
  • Ctrl + 2 : 활짝 (exp_laugh)
  • Ctrl + 3 : 부끄 (exp_shy)
  • Ctrl + 4 : 깜짝 (exp_surprise)
  • Ctrl + 5 : 삐짐 (exp_angry)
  • Ctrl + 6 : 시무룩 (exp_sad)
  • Ctrl + 7 : 졸림 (exp_sleep)
  • Ctrl + 8 : 초롱 (exp_01)
  • Ctrl + 9 : 신남 (exp_laugh2)
  • Ctrl + 0 : 기본 표정 초기화 (배율 유지)

[ 크기 및 배율 조절 ]
  • Ctrl + [ : 캔버스 창 크기 50px 축소
  • Ctrl + ] : 캔버스 창 크기 50px 확대
  • Ctrl + - : 캐릭터 모델 배율 0.2 축소 (0.4x ~ 3.0x)
  • Ctrl + + (또는 =) : 캐릭터 모델 배율 0.2 확대

[ 자막 및 대사 설정 ]
  • Ctrl + U : 실시간 텍스트 표시 ON / OFF 토글
  • Ctrl + J : 대사 표시 방식 순환 전환 (말풍선 ↔ 하단 자막 ↔ 자막 숨김)

[ 독립 환경설정 창 ]
  • Ctrl + , :
    화면과 별개로 4대 탭 독립 환경설정 창(540x650)을 토글합니다.
    (설정 창 내에서 Esc 또는 Ctrl + , 로 닫기 가능)


4. 독립 환경설정 창 4대 탭 구조 (Settings Window)
--------------------------------------------------------------------------------
단축키 Ctrl + , 로 전용 독립 설정 창을 엽니다:
- 탭 1. ✨ 감정표현 테스트:
  • 자유 대사 감정 분석 테스트기 (Auto AI / 수동 지정)
  • 8대 감정 원클릭 프리셋 카드 (눈물, 충격, 삐짐, 환호, 당당, 생각, 사랑, 촙)
- 탭 2. 🎭 캐릭터 & 디스플레이:
  • 9종 스타일/표정 제어 칩 및 초기화 (Ctrl + 0)
  • 배율(Scale), 너비(Width), 높이(Height) 슬라이더 및 프리셋 칩
- 탭 3. 💬 자막 & 대사 설정:
  • 자막 모드 활성화 스위치 (Ctrl + J)
  • 대사 표시 방식 선택 (💭 말풍선 / 📝 하단 자막 / ❌ 숨김)
  • 글자 크기(Font) 슬라이더 (10~36px) 및 프리셋 칩
  • 실시간 텍스트 표시 스위치 (Ctrl + U) 및 실시간 자막 미리보기 박스
  • ⚡ PC 리소스 과부하 자동 감지 경고 스위치 (CPU/RAM 90% 초과 알림)
- 탭 4. 🎙️ 음성 & 립싱크 테스트:
  • 실시간 음성 합성 & 립싱크 테스트 셀 (대사 입력 + ▶ 재생 버튼)
  • VOICEVOX 5대 파라미터 제어 (화속, 억양, 음높이, 음량, 쉼표 간격)


5. 실행 및 종료 방법
--------------------------------------------------------------------------------
* 무음 백그라운드 실행:
  - start_zundamon.vbs 실행 (콘솔 창 없이 투명 윈도우 기동)

* 콘솔 실행:
  - start_zundamon.bat 실행

* Windows 작업 스케줄러 실행:
  - PowerShell / 명령 프롬프트: schtasks /run /tn "ZundamonMascot"

* 프로그램 종료:
  - 작업 관리자(Ctrl+Shift+Esc)에서 'pythonw.exe' 프로세스 종료
  - 또는 PowerShell에서: Stop-Process -Name pythonw -Force


6. 음성 발화 CLI (speak.py)
--------------------------------------------------------------------------------
한국어 텍스트를 전달하면 일본어 음소 변환을 거쳐 즌다몬 음성으로 발화하며 립싱크합니다.
텍스트 감정에 따라 표정과 모션, 음성 스타일이 실시간 자동 연동됩니다:

  실행 예시:
  python speak.py "안녕하세요! 즌다몬인 것이다!"
  python speak.py --emotion joy_cheer "모든 문제 해결에 대성공한 것이다! 만세!"
  python speak.py --emotion crying "오류가 발생해서 너무 슬픈 것이다 ㅠㅠ"
